# PROMO SKY IN CORSO

Comparatore offerte Sky single-page autocontenuto.

## Live
https://promosky.vercel.app

## Struttura
- `index.html` — applicazione completa (HTML+CSS+JS+immagini embeddate base64)
- `sources/` — locandine PNG originali in alta risoluzione (backup, non referenziate dall'HTML)

## Promo gestite
- Sky WiFi (Only) · Standard / Open Fiber / FiberCop
- 3P · Sky WiFi + Sky TV (+ Sport/Cinema) · Standard / OF / FiberCop
- 4P · Sky Glass + WiFi + TV + Sport/Cinema + Netflix
- Only TV · Sport + Insider · Sport + UHD + Insider · Netflix · Cinema + Calcio · doppio sconto (Netflix + Cinema + UHD)
- Sky Glass (acquisto unico 43"/55")
- Sky WiFi Business (Standard / OF+FC) — prezzo bloccato 12 mesi, senza vincoli

## Note
Le immagini delle locandine sono embeddate come data URI JPEG nel singolo `index.html` per garantire funzionamento offline e via single-file deploy (Vercel).
